# Logos

The clinic's logo files, copied as supplied (PNG, transparent where noted). The logo ink is `rm-logo-navy` (#2C326D), a deeper navy than the site's text ink. Use the files; never redraw, recolour, stretch or re-set the logo in a font.

| File | What | Use it |
|---|---|---|
| `rm-full-logo-blue.png` | "RM" monogram tile and "Restoration Medical" in serif, navy on transparent, 6284 by 1000px | The original full logo, kept for reference. In use, set the name in Fraunces beside the monogram instead. |
| `rm-mark-blue.png` | The "RM" monogram alone, navy on transparent, 1000 by 1000px | Small spaces on white: favicons, stamps, a running footer. |
| `rm-mark-white-on-blue.png` | The "RM" monogram in white on a navy square, 1000 by 1000px | App icons, avatars and the small tile beside the clinic name in a handout header (round its corners to `radius` 7px at 26px). |

- Clear space: at least half the monogram's height on every side.
- On navy, photos or any ground darker than the tint colours, use `rm-mark-white-on-blue.png`; there is no all-white full logo in this system yet.
- Pair the logo with Instrument Sans for the service line ("Medical Aesthetics, Thornhill"), never with a second serif.
- The logo in use is the monogram tile beside "Restoration Medical" set in Fraunces 500 (clinic decision, November 2026; see Wordmark). The full logo file, with its own serif lettering, is kept as the original artwork.
